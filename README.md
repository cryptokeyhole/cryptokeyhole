# CryptoKeyhole

**[cryptokeyhole.com](https://cryptokeyhole.com)** is an independent crypto analytics site: on-chain and market charts, dashboards and indicator guides for Bitcoin, Ethereum and a growing list of coins. Bitcoin and Ethereum metrics are calculated from our own full nodes and refreshed every hour, and every chart explains its method and source.

- **[Indicator guides](https://cryptokeyhole.com/learn/):** what MVRV, NUPL, SOPR, the Puell Multiple, the Pi Cycle indicators, hash rate and others measure, and how to read them.
- **[Free API, Google Sheets, Excel and Python](https://cryptokeyhole.com/data-access/):** daily, weekly, monthly and yearly values of the Free charts with full history, no key needed.
- **[MCP server](https://cryptokeyhole.com/mcp/):** connect AI assistants and agents to the same data at `https://cryptokeyhole.com/api/v1/mcp`. Read-only, no account or key.
- **[Free chart embeds](https://cryptokeyhole.com/embed/)** for blogs, newsletters and forums.

## Repositories

- **[cryptokeyhole-mcp](https://github.com/cryptokeyhole/cryptokeyhole-mcp):** setup for the hosted MCP server in Claude, Cursor, VS Code and other clients, with the tool list and example prompts.
- **[onchain-indicators](https://github.com/cryptokeyhole/onchain-indicators):** a plain-English reference to on-chain and market indicators, with formulas, how to read them, their limits and links to live charts.
